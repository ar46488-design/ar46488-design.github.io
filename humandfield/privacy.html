Privacy Policy: HumAndField Studio

Last updated: November 4, 2026

HumAndField Studio is a private tool used only by the owner of the YouTube channel Hum & Field to manage that channel. This policy explains what it accesses and what it does with it.

What it accesses

Through the YouTube Data API (YouTube API Services), and only for the owner's own channel: the channel's basic details, its videos and playlists, and the public comments posted on its videos. It uploads the channel's own videos and thumbnails, adds them to playlists and posts replies to comments.

What it stores

The Google sign-in token is stored only on the owner's own computer. Comment text and author display names are kept in a local database on that computer so the same comment is not answered twice. Nothing is sent to any other server, sold, shared or used for advertising.

Comment text and AI drafting

To write a short reply, the text of a public comment may be sent to an AI model provider (Anthropic) used by the owner. No other personal data is sent.

Google and YouTube

This tool uses YouTube API Services. By using YouTube you agree to the YouTube Terms of Service; see also the Google Privacy Policy. You can revoke this tool's access at any time at myaccount.google.com/permissions.

Deleting data

Revoking access stops all use immediately. To have locally stored comment data deleted, or for any question, write to ar20043956@gmail.com.
